Como funciona

.exe moderno: o RetroHub pode catalogar o jogo e iniciar/baixar o arquivo para execução no Windows local. O Chrome/Vercel não pode executar nativamente um .exe dentro da página.

Jogar dentro do navegador: requer um backend Windows com streaming ou um runtime WebAssembly específico. O módulo está preparado para receber essa integração sem fingir compatibilidade inexistente.

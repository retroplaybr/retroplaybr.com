RetroHub v4.4 - PC / Windows

Esta base adiciona uma área PC/Windows para arquivos .exe modernos.
IMPORTANTE: Vercel/Chrome não executa nativamente executáveis Windows dentro de uma página web.
Para jogar remotamente dentro do navegador, conecte um host Windows/VM e uma camada de streaming.
Para jogos antigos, um runtime DOS/Win9x em WebAssembly pode ser integrado separadamente.

Use somente software/jogos que você tenha autorização para usar e disponibilizar.

RETROHUB — PUBLICAR PARA TODOS

1. Envie TODOS os arquivos e a pasta api/ para o repositório conectado à Vercel.
2. O Vercel Blob retrohub-games precisa estar conectado ao projeto.
3. Em Vercel > Project > Settings > Environment Variables, crie ADMIN_PASSWORD.
4. Faça novo deploy.
5. Abra /admin.html, entre com a senha e use “🌐 Publicar para todos”.

Arquivos públicos no Blob podem ser acessados por quem tiver a URL. Use apenas conteúdo que você tenha autorização para distribuir.
